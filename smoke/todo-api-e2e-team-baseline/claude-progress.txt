- **Tech Stack:** Node.js, TypeScript, Express, Vitest, Supertest, npm
- **Coding Style:** TypeScript strict mode. Export Express app as factory (no listener) for testability. Entry point in src/index.ts calls listen().
- **Test Pattern:** Vitest + Supertest. Test files in tests/ directory named *.test.ts. Use supertest(app) to make HTTP assertions without starting a server.
- **Build/Test Commands:** `npm install` (restore), `npm run build` (compile TS), `npm test` (run vitest)
- **Key Files:** src/app.ts (Express factory), src/index.ts (entry point), src/store.ts (TodoItem interface + in-memory persistence), src/routes/todos.ts (route handlers)
- **Error Responses:** All errors must be JSON. Use 400 for validation, 404 for not-found, with descriptive messages.
- **In-Memory Store:** No database — use a simple array/map for persistence. Store resets between server restarts. Tests should handle store isolation (reset between tests).
